> 代码本体在另一个仓库：[parking-lot-management-system](../parking-lot-management-system)

## 项目简介

基于 JSP + Servlet + MySQL 的停车场管理系统，实现车辆进出管理、车位监控、收费结算等功能。

- **前端**：JSP / HTML / CSS / JavaScript
- **后端**：Java Servlet
- **数据库**：MySQL
- **服务器**：Tomcat 8.0
- **架构**：MVC
